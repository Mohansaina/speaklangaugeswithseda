# Seda Oruç — Language Lessons Website

A modern, responsive, high-craft website for **Coach Seda Oruç**, multilingual language educator based in Baku, Azerbaijan (8 Noyabr Metro) and online worldwide.

---

## 🌟 Features & Highlights

- **Reference-Faithful Design**: Modeled directly on high-converting language coach designs:
  - Hero Section with Coach Seda's portrait and bold `START A COURSE` CTA.
  - About Section with the signature golden yellow card (`#eab308`) and personal conversational narrative.
  - Clean Language Courses catalog with level filters and transparent details.
- **4 Languages Supported**:
  - 🇬🇧 **English**: Fluency mastery & IELTS Band 7.5+ preparation.
  - 🇩🇪 **Deutsch (German)**: Goethe-Zertifikat A1–B1 & relocation coaching.
  - 🇷🇺 **Русский (Russian)**: Practical everyday spoken Russian for Baku and business.
  - 🇹🇷 **Türkçe (Turkish)**: Fluent spoken Turkish with an authentic Istanbul accent.
- **Baku Studio & Online**:
  - Detailed classroom guide for in-person immersion right at **8 Noyabr Metro**, Baku.
  - Strict maximum of 4 learners per group for maximum speaking time.
  - Online Zoom coaching available worldwide.
- **Dual-Optimized Layout**:
  - Clean 12-column editorial grid on **laptop / desktop**.
  - Thumb-friendly, touch-ergonomic single-column flow on **mobile phones** (zero horizontal scroll, iOS Safari 16px auto-zoom prevention).
- **Direct WhatsApp & Instagram Integration**:
  - 1-click WhatsApp chat prefilled with course details.
  - Direct link to `@seda_oruc_english`.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: TypeScript
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Google Fonts (*Plus Jakarta Sans* & *Fraunces*)
